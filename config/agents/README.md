Each subdirectory is one independent research agent: own `watchlist.json`, `weights.json`, `risk-limits.json`, and either `personality.md` (flat) or `master.md` + `buy-playbook.md` (split).

The compact runtime mandate is what `jobs/research-scan.js` reads and `lib/ai-overlay.js` appends to the AI's system context. Agent 2 and Agent 3 still use one flat `personality.md`. Agent 1 is the split-mandate pilot: `master.md` (identity, philosophy, universe guardrails — applies to every task) and `buy-playbook.md` (entry search/sizing) get concatenated at load time into the same slot `personality.md` used to fill — see `MANDATE-SPLIT-PILOT.md` for exactly how and why, and how to repeat it. Agent 1 also has a `sell-playbook.md`, which is documentation only (not loaded by any job) — exit decisions stay fully deterministic in `lib/mandate-policy.js` / `config/agents/mandate-policy.js`, never AI-reasoned.

Every agent's fuller versioned specification sits beside its compact files as `AGENT-*-PLAN.md`. Keep all forms aligned with their canonical mandate sources. A compact prompt is not permission to bypass deterministic gates, ownership, evaluator review, or human approval.
