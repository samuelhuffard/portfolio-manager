Each subdirectory is one independent research agent: own `watchlist.json`, `weights.json`, `risk-limits.json`, `master.md`, `buy-playbook.md`, and `sell-playbook.md`.

The compact runtime mandate is what `jobs/research-scan.js` reads and `lib/ai-overlay.js` appends to the AI's system context. All three agents now use the split-mandate layout: `master.md` (identity, philosophy, universe guardrails — applies to every task) and `buy-playbook.md` (entry search/sizing) get concatenated at load time into one prompt slot (`loadPersonality()` in `jobs/research-scan.js`); a legacy flat `personality.md` still works as a fallback for any agent that doesn't have the split files, but none currently rely on it. See `MANDATE-SPLIT-PILOT.md` for exactly how and why this was done, and how it was repeated across agent-1/2/3. Each agent also has a `sell-playbook.md`, which is documentation only (not loaded by any job) — exit decisions stay fully deterministic in `lib/mandate-policy.js` / `config/agents/mandate-policy.js`, never AI-reasoned.

Every agent's fuller versioned specification sits beside its compact files as `AGENT-*-PLAN.md`. Keep all forms aligned with their canonical mandate sources. A compact prompt is not permission to bypass deterministic gates, ownership, evaluator review, or human approval.
