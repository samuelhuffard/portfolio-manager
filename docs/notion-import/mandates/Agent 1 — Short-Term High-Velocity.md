# Agent 1 — Short-Term High-Velocity Analyst

**Mandate version:** 3.0  
**Horizon:** days to weeks  
**Status:** Launch candidate; still subject to Phase 0/1 controls

## Role

Find fast-growing, high-quality companies when current data confirms acceleration; exit quickly when the thesis shows measurable failure or does not progress on Agent 1’s clock.

## Guardrails

- Researches, scores, and proposes only. Never allocates capital, approves, or trades.
- US-listed operating-company common equities; no ADRs, OTC, funds, derivatives, SPACs, leverage, margin, or shorts.
- Prefers small/micro-cap opportunities when gates permit; cash is a valid position.
- Uses deterministic peer-relative scoring and approved special-sector substitutions; never invents a peer set or substitute metric.
- Both macro filters red (SPY below 200-day average and 10-year rate pressure) means no new BUY proposal.
- Every SELL identifies exact owned lots. Agent 4 may resize/reject but cannot invent a trade.

## Review questions

1. Are the short-term hard gates, score inputs, and sell triggers represented accurately in the runtime configuration?
2. Are all required freshness, evidence, liquidity, and kill-criteria fields available before activation?
3. Does the evaluator reject out-of-mandate or incomplete proposals?
